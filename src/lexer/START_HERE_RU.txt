ЧТО СДЕЛАТЬ ПРЯМО СЕЙЧАС

1. Распакуйте архив.
2. Откройте терминал в папке project-d-lexer.
3. Проверьте Java командой:
   java --version
4. Запустите самый короткий пример:
   java -jar project-d-lexer.jar examples/01_simple.d
5. Запустите два примера из слайдов 6 и 7:
   java -jar project-d-lexer.jar examples/02_calculator.d
   java -jar project-d-lexer.jar examples/03_nested_values.d
6. Откройте в IDE файлы src/Lexer.java, src/Token.java и src/TokenType.java.
7. Прочитайте DEMO_SCRIPT_RU.txt и распределите части между участниками.

НА ЗАЩИТЕ

Не запускайте сразу все примеры: вывод получится слишком длинным.
Сначала покажите 01_simple.d. Затем отдельно запустите один из больших примеров,
который соответствует вашему слайду.

Если преподаватель просит изменить входной код, отредактируйте любой файл .d,
сохраните его и снова выполните ту же команду java -jar.

Важно: программа сейчас демонстрирует только lexer. Она не вычисляет 42, 360 или 7,
потому что выполнение программы относится к будущему interpreter.
